# 🚀 Mohamed Alaa Portfolio

A modern, responsive Flutter web portfolio showcasing skills and projects as a Flutter developer.

## 🚀 Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Dark Theme** - Modern dark UI with purple/blue gradients
- **Interactive Animations** - Smooth hover effects and transitions
- **Real Brand Icons** - SVG icons for technologies (Flutter, Dart, Firebase, etc.)
- **Professional Layout** - Hero section, skills, projects, experience, and contact

## 🛠️ Technologies Used

- Flutter Web
- Dart
- SVG Icons
- Google Fonts
- Responsive Design

## 💻 Development

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/memo_portfolio.git

# Navigate to project directory
cd memo_portfolio

# Install dependencies
flutter pub get

# Run the web app
flutter run -d web-server --web-hostname localhost --web-port 8080
```

## 📦 Building for Production

```bash
# Build for web
flutter build web --release

# The build files will be in build/web/
```

## 🚀 Deployment Options

### 1. GitHub Pages (FREE)
- Push to GitHub repository
- Enable GitHub Pages in Settings
- Automatic deployment via GitHub Actions

### 2. Vercel (FREE)
```bash
npm i -g vercel
vercel --prod
```

### 3. Netlify (FREE)
- Drag & drop build/web folder to Netlify
- Or connect GitHub repository

### 4. Firebase Hosting (FREE)
```bash
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```
